JSON format help

Each entry in rowDefs is one row of buttons on the Event Capture page, with an optional gridCols (e.g. "grid-cols-4") and an array of buttons. Each button needs an event (unique identifier), text (display label), and color (btn-blue, btn-red, btn-green, btn-yellow, btn-orange, btn-gray). Buttons can also set lead and lag: the seconds of video to include before and after the press in the exported clip (default 5).
