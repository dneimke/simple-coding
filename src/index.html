Each entry in rowDefs is one row of buttons on the Event Capture page, with an optional gridCols (e.g. "grid-cols-4") and an array of buttons. Each button needs an event (unique identifier), text (display label), and color (btn-blue, btn-red, btn-green, btn-yellow, btn-orange, btn-gray).

Configurations are saved in your browser's local storage. Changing the selection loads it into the editor. Save updates the selected configuration and applies it on the Event Capture page; Save as stores the editor under a new name.
