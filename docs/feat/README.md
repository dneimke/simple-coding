# Feature Prototypes and Specs

This folder holds work-in-progress designs for features that have not been built into the app yet. Each feature gets its own subfolder containing a `spec.md` (the problem, the proposal, open questions and recorded decisions) and, where useful, a static `prototype.html` that can be opened directly in a browser from disk to give feedback before implementation planning starts.

Nothing in this folder is deployed: GitHub Pages only publishes `src/`.

| Feature | Status |
| --- | --- |
| [Sticky zone board](sticky-zones/spec.md) | In app (default board) |
| [Single-pass compound tagging](single-pass-coding/spec.md) | Prototype ready for feedback |
