JSON format help

Each entry in rowDefs is one row of buttons on the Event Capture page, with an optional gridCols (e.g. "grid-cols-4") and an array of buttons. Each button needs an event (unique identifier), text (display label), and color (btn-blue, btn-red, btn-green, btn-yellow, btn-orange, btn-gray). Buttons can also set lead and lag: the seconds of video to include before and after the press in the exported clip (default 5).

Team boards (like hockey-one-zoned) add a zones block and rows with "team": 1 or 2. A team row can hold several grids; its buttons take the team's colour and code (e.g. FIRE BS), and buttons with "zoned": true also add the active zone (FIRE BS2). A row with "team": "selected" shows a team toggle and logs for the selected team.

Configurations are saved in your browser's local storage. Changing the selection loads it into the editor. Save updates the selected configuration and applies it on the Event Capture page; Save as stores the editor under a new name.
